# 语言文件（自定义翻译）

本目录存放 LookImage2 的**外部语言包**。程序内置中文（`zh`）与英文（`en`），
其余语言均通过此处的 JSON 文件在运行时加载，无需重新编译即可扩展界面语言。

## 1. 文件位置与命名

- 目录：程序 `exe` 所在目录下的 `res/lang/`
  （开发环境即源码仓库的 `res/lang/`，打包后随 `res/` 一起分发）。
- 文件名：`<语言码>.json`，例如 `ja.json`、`de.json`、`ru.json`。
  - 语言码不区分大小写，加载时统一转为小写；建议始终使用小写文件名。
  - 文件名的语言码（不含扩展名）即为该语言在程序内部的唯一标识。

放置或修改文件后，**重新打开设置面板的「语言」下拉框**即可看到并切换到该语言，
无需重启整个程序（语言切换为运行时热加载）。

## 2. 文件格式

标准 JSON，键为程序内部的翻译键（如 `menu.open`），值为对应语言的文本。
约定键 `__name__` 用于在下拉框中显示的语言名称（建议填写该语言的 native 写法，如 `日本語`）。

```json
{
  "__name__": "日本語",
  "menu.open": "開く",
  "menu.save_as": "名前を付けて保存",
  "settings.title": "設定"
}
```

- 仅需包含你想要翻译的键；**未填写或值为空字符串的键会自动降级为英文**。
- 若 JSON 解析失败，该文件会被忽略并在日志中提示，不影响其他语言。
- 键名必须与程序内部一致（见下方「如何获取完整键列表」）。

## 3. 占位符说明

部分文本包含 `{}` 占位符，由程序在运行时替换为动态内容（如数字、文件名）。
自定义翻译时请**保留 `{}` 的数量与顺序**，例如：

```json
"about.version": "バージョン {}",
"save.success_quality": "保存しました · 品質{} · {}"
```

不要把 `{}` 写成全角 `｛｝` 或 `{0}`，程序按原始 `{}` 进行内插。

## 4. 如何获取完整键列表

程序内置的全部翻译键定义于源码 `src/lang.rs` 的 `ENTRIES` 数组中
（每个键形如 `("键名", ("中文", "英文"))`）。

最简便的方法是复制一份现有语言文件作为模板，再逐条替换文本：

- `ja.json` / `de.json` / `ru.json`：已是完整的示例，可直接另存为新语言码后修改。
- 建议以 `en` 列（= `ENTRIES` 中的英文）为基准，逐项翻译为目标语言。

## 5. 示例：新增一门语言（法语）

1. 复制 `de.json` 为 `fr.json`。
2. 将 `__name__` 改为 `Français`。
3. 把每个值翻译成法语，保留 `{}` 占位符。
4. 启动程序，打开「设置 → 语言」，即可在下拉框中看到 `Français` 并选用。

## 6. 注意事项

- 技术格式类键（如 `assoc.*`、`save.filter_*`、`exif.*`、`sq.low/medium/high/max`）
  通常保持英文即可，无需强制翻译。
- 语言选择会被记忆，下次启动自动恢复（配置写入 `config`）。
- 若某语言文件在下拉框中不出现，请检查：文件名是否为 `<code>.json`、JSON 是否合法、
  `__name__` 是否为空、以及文件是否位于 `exe` 旁的 `res/lang/` 目录。
